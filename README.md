# Smart Downloads Organizer

Python automation that runs in the background and sorts the Downloads folder automatically.

## Features
- Sorts files by type: Images, Videos, Movies, PDFs, Excel, Documents, APK, Audio, Zips
- Detects the source: ChatGPT, Gemini, WhatsApp, or the website it came from
- Separate Screenshots folder
- Moves loose folders into a Folders folder
- Checks every 10 seconds, so new downloads are sorted automatically

## How to run
python organizer.py
